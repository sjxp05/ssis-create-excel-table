### 실행 방법

1. venv 환경 세팅

    ```pwsh
    python -m venv .venv
    ```

2. venv 가상환경 활성화\
   (\* 3, 4는 활성화 시킨 상태에서 실행해야 됨!)

    ```bash
     .venv\Scripts\Activate # Windows
     source .venv/bin/activate # Mac
    ```

3. 필요한 라이브러리 다운로드

    ```pwsh
    pip install -r requirements.txt
    ```

4. 실제 조견표 준비\
   실제(내부등록용) 조견표는 내부 자료이므로 저장소에 포함하지 않는다.\
   각자 전달받은 파일을 아래 경로로 복사한다.

    ```
    xlsx_files/조견표_2026.xlsx
    ```

5. (결제단가표까지 만들 경우) 고시에서 단가 추출\
   고시 hwpx 파일에서 서비스별 단가를 추출해 `params/단가_파라미터.json`으로 저장한다.\
   (이 단계를 건너뛰면 main.py는 기본 단가표까지만 생성)

    ```pwsh
    python -m app.gosi_reader "<고시파일.hwpx>"
    ```

6. main.py 실행
    ```pwsh
    python -m app.main
    ```
5. 가상환경 비활성화
    ```pwsh
    deactivate
    ```

### 파이프라인 구조

```
실제 조견표 ──(jogyeon_reader + table_writer)──> 기본급여 단가표 (950행)
                                              x
고시 hwpx ──(gosi_reader)──> params/단가_파라미터.json ──(payment_master)──> 서비스 단가 25조합
                                              |
                                              v
                              결제단가표 (23,725행 + 단가근거 시트)
```

### 실제 조견표 대응 리더 (jogyeon_reader)

실제 조견표는 종합조사 시트 레이아웃이 `조견표_샘플.xlsx`와 달라서
(같은 앵커 문구가 두 번 등장, 확장형 15구간 값은 하단 별도 보정표에 존재),
기존 코드를 재사용하면서 종합조사 읽기만 보완한 별도 리더
`app/jogyeon_reader.py` 를 만들어 실제 조견표에서 최종 결제단가까지 산출한다.

- 인정조사/산정특례는 기존 `table_reader` 의 함수를 그대로 재사용
- 종합조사는 완전한 표('1등급'까지 헤더를 갖춘 블록)만 본표로 인식하고,
  하단 보정표(확장형 15구간) 값을 본표에 반영한 뒤 읽는다
- 기존 `read_jh_table` 은 수정하지 않고 그대로 유지
- 검증: 실제 조견표로 생성한 기본급여 단가표(950행)와 결제단가표(23,725행)
  모두 2026년 공식 단가표와 전수 일치 확인

참고: `xlsx_files/조견표_샘플.xlsx` 는 데모용 샘플로, 종합조사 본인부담금 일부가
이전 연도 값이라 공식 단가표와 다르다. 실제 산출에는 조견표_2026을 사용할 것.

### 담당자 수정 지점 (코드 수정 없이 파일만)

| 상황 | 수정할 파일 |
| --- | --- |
| 단가 금액이 틀렸을 때 | `params/단가_파라미터.json` 의 해당 `금액` (근거는 옆의 `출처` 참고) |
| 고시에서 서비스 명칭이 바뀌었을 때 | `params/앵커_키워드.json` 의 해당 `제목` |

값이 이상하면 실행 시 검증에서 멈추고, 문제의 값과 고시상 위치(장 > 항목 > 표 > 행)를 안내한다.

### 검증

생성한 결제단가를 공식 파일과 전수 대조하려면:

```pwsh
python -m app.payment_writer <기본단가표.xlsx> <출력.xlsx> <연도> <차수> [검증용 공식파일.xlsx]
```
